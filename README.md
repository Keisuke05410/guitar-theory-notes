# kaie ギター理論ノート

会社の軽音サークルでバンド「廻会」のギターを担当している。ギターは1本。自作曲「kaie」のギターフレーズを作るために、必要な音楽理論を自分の言葉で残す個人ノート。

## 目的

- 「kaie」で迷ったときに、キー・スケール・コードトーンへ戻れるようにする。
- 学んだことを指板上の形と、曲のどの小節で使うかに結びつける。
- メンバーからの修正依頼を `songs/kaie.md` に残し、理論ページと行き来しながらフレーズを直す。

## フォルダ構成

```text
.
├── README.md
├── theory/          # 理論テーマごとのページ
├── songs/           # 曲ごとのメモ（コード、構成、修正依頼）
└── templates/       # 新しいテーマページ用の雛形
```

## 次に読むページ

1. [kaie](songs/kaie.md) で、キー未確認・コード進行・修正依頼の現状を確認する。
2. [キーとダイアトニックコード](theory/01-key-and-diatonic.md) で、曲のキーを決める材料を揃える。
3. キーが仮でも置けるようになったら、[ペンタトニック](theory/02-pentatonic.md) と [コードトーン](theory/03-chord-tones.md) を順に読む。

## 使い方

1. 新しいテーマを足すときは [templates/page-template.md](templates/page-template.md) を `theory/` にコピーし、番号とタイトルを付ける。
2. 各ページ末尾の「Q&A」欄に、練習中に出た質問と、あとから分かった答えを追記していく。
3. 「kaieのどこで使えるか」には、曲のセクション名（イントロ、Aメロ、サビなど）を書いて、抽象的な理論のままにしない。
4. 曲側の修正依頼やコード進行の更新は `songs/kaie.md` に書く。理論の説明は `theory/` に残す。
5. 目次と「次に読むページ」は、ページを増やしたときにこの README も更新する。
